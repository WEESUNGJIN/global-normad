## 📘 In My Day

[배포 링크](https://inmyday.vercel.app)

> **프로젝트 기간:** 2025.09.29 ~ 2025.11.03

> **팀명:** Part4_2팀

> **주제:** 원데이 클래스 예약 플랫폼

> **설명:** 다양한 원데이 클래스를 손쉽게 등록하고 예약할 수 있는 서비스입니다.
> 사용자는 판매자이자 체험자가 되어 자신이 만든 클래스를 등록하거나 다른 사용자의 클래스를 예약할 수 있습니다.

---

## 🚀 프로젝트 개요

### 🎯 주제 및 선정 배경

* 최근 **원데이 클래스 시장**의 성장과 함께, 누구나 쉽게 클래스 운영자가 될 수 있는 플랫폼의 필요성을 느꼈습니다.
* **판매자와 체험자의 경계가 없는 플랫폼**, 즉 “나도 만들고, 나도 체험하는” 구조를 구현하고자 했습니다.
* 캘린더/지도 SDK를 통해 **날짜별 예약 가능 시간과 위치 기반 탐색**이 가능한 시스템을 구축했습니다.

---

## 💡 서비스 컨셉

* 다양한 원데이 클래스를 **등록 및 예약**할 수 있는 플랫폼
* 사용자는 **판매자이자 체험자**로, 자신이 만든 클래스를 올리거나 다른 사용자의 클래스를 예약 가능
* **캘린더 뷰 SDK**와 **지도 SDK**를 활용하여 예약 가능한 날짜/시간/위치 확인
* 후기 시스템과 단일 체험 중심의 예약 구조로 직관적인 UX 제공

## 🎨 주요 페이지별 설명

### 🔐 회원가입 / 로그인

* 이메일, 비밀번호, 닉네임 입력 후 자동 로그인
* 비밀번호 정규식(영문+숫자, 8자 이상) 검증
* 카카오 로그인 시 추가정보 입력 후 자동 가입/로그인 처리
* `zustand/persist`로 로그인 상태 유지

### 🏠 메인 페이지 (/)

* 이벤트/신규 클래스 배너
* 키워드 검색, 카테고리/가격 필터링
* 인기 체험(후기순 정렬) / 최신순 리스트
* 반응형 UI (모바일: 가로 스크롤, PC: 버튼 네비게이션)

### 🧾 체험 상세 페이지 (/experience-detail/[id])

* 소개 이미지(1~4장) 슬라이드
* 카카오 지도 기반 위치 표시
* 예약: 날짜 → 시간 → 인원 → 금액 확인
* 호스트와 일반 사용자 UI 분기 처리
* 수정/삭제 기능 및 예외 처리(alert 표시)

### 👤 마이페이지

* 내 정보 수정 (닉네임, 비밀번호 검증)
* 예약 내역 (무한 스크롤, 필터링, 후기/취소 모달)
* 내 체험 관리 (등록/수정/삭제, 예외 처리 포함)
* 예약 현황 캘린더 (월별 대시보드, 실시간 뱃지 갱신)

## 🧠 예외 처리 & 개선 사례

### 🩹 로그인 상태 복원 오류

* 문제: 새로고침 시 Zustand 상태가 초기화되어 로그인 정보가 사라짐
* 해결: persist 미들웨어와 onRehydrateStorage 콜백으로 복원 시점 제어하여 복원 완료 전 렌더링 지연 처리

### 🩹 useSearchParams 훅 사용 오류

* 문제: Next.js App Router 환경에서 useSearchParams() 사용 시 클라이언트 렌더링 단계에서 hydration 오류 발생
* 해결: 훅 대신 searchParams를 props 형태로 전달받아 사용하는 방식으로 변경해 빌드 및 런타임 오류 해결

### 🩹 예약 변경 중복 처리 오류

* 문제: 마이페이지에서 ‘예약 변경’ 클릭 후 시간/인원 수정 시 “이미 신청한 예약입니다.” 오류 발생
* 해결: 상세 페이지 이동 시 mode=edit과 reservationId 쿼리 추가, 수정 중인 예약은 중복 검사에서 제외 처리

### 🩹 프로필 이미지 404 및 비지속성 문제

* 문제: 새로 업로드한 프로필 이미지가 새로고침 후 사라지거나 404 오류 발생
* 해결: POST /users/me/image 후 PATCH /users/me 요청 추가로 DB 영구 저장, teamId 중복 경로 제거

### 🩹 예약된 체험 삭제 시 UI 미갱신 문제

* 문제: 예약이 있는 체험 수정 시 백엔드 에러 후에도 UI가 갱신되지 않거나 수정 완료 모달 미표시
* 해결: onError 시 alert 추가, DateSection key 변경으로 리렌더링 유도, queryClient.invalidateQueries로 최신화, window.location.reload() 제거

### 🩹 예약 현황 뱃지 실시간 반영 오류
* 문제: 예약 승인/거절 시 캘린더 뱃지 숫자가 즉시 반영되지 않거나 중복 반영되는 현상 발생
* 해결: requestAnimationFrame()으로 렌더 완료 후 상태 변경, useRef 기반 badgeUpdatedIds Set으로 중복 업데이트 방지

### 🩹 캘린더 패널 좌표 이동 오류
* 문제: 월 전환 후 특정 날짜 클릭 시 패널이 (0,0) 위치로 점프하거나 화면 밖으로 벗어남
* 해결: DOM 렌더 완료 후 requestAnimationFrame()으로 안전한 시점에 scrollIntoView() 실행, useScrollIntoView 훅으로 공통화

### 🩹 예약된 일정 삭제 시 폼 상태 불일치
* 문제: 예약 일정 삭제 후 서버 데이터와 폼 상태가 불일치하여 UI 반영 지연
* 해결: queryClient.invalidateQueries로 최신 데이터 즉시 갱신, form.schedules 재세팅으로 상태 동기화
